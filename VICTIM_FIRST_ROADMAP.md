# Victim-First Roadmap

## V1.5 — Safety Around Me
1. **Silent Safety Session** — help can start without an obvious panic-screen interaction.
2. **Safety Map** — answer “am I physically alone?” without publishing people's identities/exact locations.
3. **Safety Compass** — answer “which way gets me to verified human help?” with minimal cognitive load.
4. Existing Trusted Circle + Live Track remain the authoritative emergency-sharing layer.

## Next milestone — ViraRelay / ViraMesh
When internet fails, encrypted SOS packets should be relayed by nearby participating ViraNari devices until one reaches a gateway with connectivity.

## Later
- Nearby responder opt-in workflow with anti-abuse rules.
- Institution/campus Safe Node administration.
- Push notifications.
- PostgreSQL + Alembic + Redis presence TTL.
- Native iOS background-behavior hardening.
