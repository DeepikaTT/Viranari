# Upgrade to ViraNari V1.8.2

## Existing Git repo
Prefer the separate `viranari_v1_8_2_sync_patch.zip` and run:

```fish
./apply_sync_v1_8_2.fish ~/Projects/Viranari
```

Then:

```fish
cd ~/Projects/Viranari/mobile
flutter clean
flutter pub get
flutter analyze
flutter build apk --release
```

The apply script also runs `scripts/patch_mobile.py` against the existing Android wrapper. This installs the native notification-bar bridge and preserves `POST_NOTIFICATIONS` in the manifest.

## VPS
Backend schema is unchanged. Deploy the V1.8.2 backend source and restart the existing service/PM2 process. Keep `.env`, database and venv.

Expected health version: `1.8.2`.

## Android notification permission
On Android 13+, allow ViraNari notifications when prompted. If previously denied, enable them under App info → Notifications.

## Notification limitation
Notification-bar alerts are generated by the app after inbox polling detects an SOS. They work while the ViraNari process is alive enough to poll. Reliable delivery after force-stop/process death needs push delivery (FCM/APNs), which is not claimed in this release.
