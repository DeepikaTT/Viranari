# ViraNari V1.8 — Jury feature points

- **Silent Safety Session:** hold the shield logo; emergency starts discreetly.
- **Incoming SOS takeover:** full-screen pulsing SOS alert stays until the trusted responder accepts it (while app is running).
- **Live GPS, not a static pin:** coordinates, route trail and freshness update every few seconds.
- **Two-person emergency map:** accepted responder + victim are visible together during the trusted SOS.
- **Live distance + Approx ETA:** distance recomputes as either person moves; ETA uses responder speed when available.
- **Safety Map:** anonymous opt-in nearby presence; exact identities/peer coordinates remain hidden.
- **Working radius controls:** 500 m / 2 km / 5 km filter dots, safety places, counts and zoom.
- **Safety Compass:** points toward verified Safe Nodes, with clearly-labelled public-place fallback.
- **Network-loss resilience:** last reliable position remains; victim GPS queues locally and replays on reconnect.
- **Emulator-ready demo:** ADB scripts auto-grant emulator permissions and inject moving mock GPS routes.

Not included/claimed: CCTV surveillance, emergency timeline, or guaranteed killed-app push delivery.
