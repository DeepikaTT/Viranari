# ViraNari V1.4.4 Design Spec

The visual language is intentionally restored to the V1.2 prototype rather than the minimal V1.4 dashboard.

- Warm ivory background.
- Deep teal primary text/actions.
- Lotus pink emergency emphasis.
- Antique gold accent.
- Large rounded panels and informative cards are retained.
- Home prioritises the large hold-SOS control, system status panel, emergency status and latest SOS card.
- Navigation: Home / Circle / Inbox / History.
- Location is contextual: coordinates + Open Map in emergency views, not a dedicated Map tab.
- SMS appears only as a non-functional future placeholder.
