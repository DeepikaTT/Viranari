# ViraNari V1.4.4 — Feature Summary

## Current prototype

- Press-and-hold emergency SOS.
- Real GPS coordinates.
- Continuous active-emergency location tracking.
- Android foreground/background emergency location service.
- Heartbeat-based LIVE / DELAYED / LAST SEEN state.
- Trusted Circle with consent-based invitation acceptance.
- Multi-contact SOS delivery.
- SENT / DELIVERED / ACKNOWLEDGED status.
- Emergency Inbox.
- External Open Map action using latest coordinates.
- Location-update timeline.
- Battery/network/location accuracy context.
- Offline SOS retry and offline GPS queue.
- Automatic reconnect and queued location replay.
- Emergency history.
- Practice/test mode.
- Resolve emergency and false-alarm cancellation.

## UI direction

V1.4.4 restores the V1.2 UI: Home, Circle, Inbox and History with larger informative panels instead of the later minimal dashboard redesign.

## Placeholder only

SMS fallback is deliberately shown only as a future placeholder. It does not request SMS permission or send messages in V1.4.4.
