# ViraNari V1.6.0 — Demo Features

- V2 UI + proven V4 live tracking preserved.
- Trusted Circle with consent-gated phone numbers.
- One-tap trusted-contact and emergency-service calling.
- No-data SMS fallback via the system Messages app with GPS/time/accuracy/battery prefilled.
- Encrypted cached trusted phone numbers for outage use.
- SQLite offline GPS journal: up to 100,000 queued points (~5.8 days at 5-second cadence).
- Automatic timestamp-preserving route replay when internet returns.
- Live location timeline preserved.
- Optional Verified Help responder network for enrolled institutions.
- Human-readable Incident Record backed by SHA-256 hash chaining + Ed25519 signatures.
- Signed log records exactly what was prepared/opened; it does not claim SMS delivery or successful calls without evidence.
